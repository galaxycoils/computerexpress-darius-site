# Plan: Resolve St. Catharines Digital Blank Page & Optimize Performance

## Goal
Resolve the white-screen error and optimize the site to be a "best-in-class" digital asset.

## Context
- The site renders an empty `div#root` in production, despite scripts loading with `200 OK`.
- Local `npm run preview` works, indicating a production-environment conflict (likely routing, cache, or env variable).
- Branding is now unified as **St. Catharines Digital**.

## Proposed Approach
1. **Critical Debugging:** Inject error logging into `src/main.jsx` to force the crash reason onto the DOM so it is visible in the browser, bypassing the "white screen" blindness.
2. **Environment & Dependency Audit:** Ensure all VITE_ environment variables are correctly resolved.
3. **Optimized Build Configuration:** Re-verify Vite configuration to ensure reliable chunking and asset loading.
4. **Best-in-Class QA:** Run `dogfood` and `high-perf-browser` checks once the render is fixed.
5. **SEO & UX Polish:** Final review of `Seo.jsx` and `Layout.jsx` for perfection.

3. **Analyze & Fix:** Based on the output, apply the targeted fix.
4. **Post-Fix Validation:** Once rendering, perform a `dogfood` audit (UI check, console error check).
