## FINDINGS

### [CRITICAL] Homepage missing H1
- The prerendered homepage has no `<h1>` tag in static HTML
- The lead headline uses `<h1 class="scd-lead-headline">` in the rendered #root but the `<p class="scd-intro-title">` is used for the hero intro
- Search engines weight H1 heavily. Without one, the homepage has no clear topic signal.

### [LOW] Sponsor FAQPage needs `mainEntity` wrapping
- The FAQPage schema has Question/Answer types but should be wrapped in a `mainEntity` array per Google's Rich Results specification

### [INFO] Homepage schema structure
- Uses separate PostalAddress as `@type` instead of nesting inside NewsMediaOrganization.address — minor but valid

### [INFO] Guide pages
- Already have Article schema — good for Google Discover indexing

## RECOMMENDATIONS

1. **Fix homepage H1**: Add `<h1>St. Catharines Digital | Municipal News from Official Sources</h1>` near the top of the body (can be visually hidden if needed)
2. **Wrap FAQPage in mainEntity**: Change from flat Question/Answer array to `{ @type: FAQPage, mainEntity: [...] }`
3. **Add BreadcrumbList schema**: For navigation structure
4. **Add SpeakableSpecification**: For voice search optimization (good for local news)
